# Excel RPG: El nacimiento de la aldea

Un juego de rol para aprender Excel escribiendo fórmulas de verdad. No hace falta instalar nada.

## Cómo conseguir el juego
1. Abre este repositorio en GitHub y entra en la carpeta `dist`.
2. Haz clic en el archivo `aldea.html`.
3. Pulsa el botón de descarga (el icono de la flecha hacia abajo, arriba a la derecha del archivo).

## Cómo jugar
1. Haz doble clic en `aldea.html` (se abre en Chrome, Edge, Firefox o Safari). Funciona sin internet.
2. Escribe tu nombre y lee el minitutorial.
3. En cada misión rellena las celdas indicadas en «Qué tienes que hacer» y pulsa «Entregar al mayordomo».
4. Si te atascas, pulsa «Pista»: hay tres por misión y no restan nada.
5. Atajos: flechas para moverte, F2 o doble clic para editar, Intro para confirmar, Esc para cancelar, Ctrl+D para rellenar hacia abajo.

## Guardar tu partida
- La partida se guarda sola en tu navegador. Puedes cerrarlo y seguir otro día (en el mismo navegador y equipo).
- Para llevarte la partida a otro sitio o tener una copia: pulsa «Exportar partida» (se descarga un archivo `.json`).
- Para recuperarla: pulsa «Importar partida» y elige ese archivo.
